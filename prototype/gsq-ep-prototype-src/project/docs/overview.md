# GSQ EP Prototype

GSQ EP Prototype is a Chrome-focused, desktop executive workspace for reviewing site roadmaps, delivery health, budgets, risks, capabilities, and business-review inputs in one place.

## Users

- Site leaders review strategic initiatives, delivery indicators, budget records, risks, and capability progress.
- Site contributors maintain source records in the existing SharePoint experience and use the **Site input** launch action to open that page.

## Core experience

The app defaults to THO Thousand Oaks and provides seven views in a single tab row: One pager, Status KPIs, Gantt + Budget, Budget, Risks, Capability, and Business Review. OnePager, Risks, Commentary, LeadershipAsks, BudgetTracker, IntegrationsTracker, and CapabilityTracker remain SharePoint-backed. Budget views summarize selected-site OPEX, CAPEX, depreciation, fiscal-year allocation, projects, and SPOT references from BudgetTracker. Site input opens the supplied SharePoint page in a new window; Jira and Network are not app screens.

## Design direction

A dense executive control-room interface optimized for a 1920×1080 Chrome canvas, with deep navy framing, Takeda red emphasis, compact cards, readable tabs, and a fully visible Site input pill at the right edge of the tab row.
